# Beyond Figma: features from other tools that fit the editor

Research date 2026-11-23. Every claim below was read from a page fetched or a search run in this session; URLs are in Sources. Where a page did not confirm something, it says so.

Stack assumed: project rendered in an iframe, overlay layer for UI, Node server with parse5/PostCSS source index and text-splice writes (see 00-figma-ideas.md).

| 1 | **Select element + prompt Claude about it** (screenshot of selection attached; apply as a reviewable version) | v0 Design Mode attaches an automatic screenshot of the selected element, lets you mix panel tweaks with an instruction, and "Apply" creates a normal version you can diff or revert [S1]. Lovable: select one or several elements (Cmd-click, drag-box), describe the change, prompt applies to all selected; also annotation drawing and pinned comments [S2]. Tab order in generated markup is rarely checked. | Inject axe-core into the iframe, run on demand and after edits (debounced); map each violation node to `data-oid` and paint badges in the overlay; "fix contrast" proposes the nearest token/colour that passes and writes it through the normal splice. ## Proposed milestone: "Beyond Figma"

Order reflects value for hand-tuning Claude output, and dependencies.

1. **Command palette + action registry** (S). Everything below registers actions here.
2. **Ask Claude about this selection** (M). Context bundle, scoped patch, pending edit with accept/reject/compare. Biggest differentiator; v0, Lovable, Figma Make all converge on it [S1, S2, S3].
3. **Token / CSS-variable usage map** (M). Fits the Claude-output pattern of repeated literals.
4. **Accessibility overlay** (M). axe-core in the iframe, contrast fix suggestions via tokens, tab-order chips.
5. **Responsive multi-viewport preview** (M). Mirrored selection and scroll across widths.
6. **Visual diff + Changes list before push** (M). Pixelmatch baseline vs current/remote; derived from the patch log.
7. **Persistent spacing visualisation** (S). Margin/padding/gap overlays for the selection.
8. **Export selection as PNG** (S). Playwright element screenshot; SVG later.

Later: breakpoint editing with `@media` write-back (L, needs #5 first), version scrubber, presentation mode, plugin API, reading Claude Design's generated sliders once a sample is available.

Shared dependency to flag: items 2, 5, 6 and 8 want a headless browser on the Node server (Playwright) for screenshots. That is a new dependency to approve before building.
